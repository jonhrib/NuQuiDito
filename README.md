# Operação Felipe 💜

Site de torcida para o IDEATHON FPP 2026 — Corações Conectados.

## Como usar

1. Abra a pasta `operacao-felipe`.
2. Coloque as fotos reais na pasta `fotos/`.
3. Use exatamente estes nomes:
   - `felipe-principal.jpg`
   - `felipe-01.jpg` até `felipe-09.jpg`
   - `dog-01.jpg` até `dog-04.jpg`
4. Abra `index.html` no navegador.

As imagens são opcionais: sem elas, o site mostra placeholders bonitinhos.

## Personalização rápida

- A mensagem pessoal está em `index.html`, na seção `message-section`.
- O nome e as funções dos cachorros também estão no `index.html`.
- As cores principais ficam no começo do `style.css`, dentro de `:root`.
- As mensagens aleatórias da torcida ficam no começo do `script.js`, no array `messages`.

## Publicar gratuitamente

A pasta pode ser publicada em GitHub Pages, Netlify ou Vercel. Não há backend: é um site estático.
